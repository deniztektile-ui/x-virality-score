# Первый модуль BNB Chain

Это дополнительный сборщик последних запусков Four.meme. Он показывает контракт и
кошелёк создателя, полученные из аргументов TokenCreate. Это НЕ рейтинг прибыльных
создателей. Связь с X, полная история, доходность, ликвидность, риск контракта и
продажи создателя пока не проверяются. Подключения кошелька и торговли нет.

Исходная панель X сохранена. Новая страница: http://127.0.0.1:8765/bnb/

## Доступ к данным

Нужны Python 3.8+ и действующий API-токен Bitquery с доступом к BSC Events.
Проверьте условия и квоту своего аккаунта; доступ к API не гарантирован бесплатно.
https://docs.bitquery.io/docs/authorization/how-to-generate/

Откройте https://account.bitquery.io/ → Authorization → Applications →
New Application → Tokens → Generate New Token. Токен вводится скрыто только в
локальном терминале. Скрипт держит его в памяти и не сохраняет в файлы.
Не вставляйте его в чат, команду, GitHub или board/data.json.

## Пробный запуск на Mac

Сервер панели в первой вкладке терминала оставьте работающим.
Во второй вкладке из папки проекта:

```bash
python3 bnb_monitor.py
```

После успешного запроса откройте http://127.0.0.1:8765/bnb/.
Сверьте хотя бы один контракт и кошелёк по ссылкам на BscScan.
Для повторения запроса каждые 5 минут (288 запросов за сутки):

```bash
python3 bnb_monitor.py --watch
```

Остановка: Ctrl+C. При ошибке API сборщик останавливается и помечает данные как
ошибочные; старые данные сохраняются с датой последнего успешного запроса.
Страница помечает данные устаревшими через 7 минут без успешного обновления.

## Ограничения и проверка

Каждый запрос получает только последние 100 событий по фильтру официального
примера Bitquery. Маршрутизированные запуски и события между опросами могут
пропускаться. История не накапливается. Число запусков создателя относится только
к текущей выборке и не означает его общий результат или надёжность.

Запрос основан на https://docs.bitquery.io/docs/blockchain/BSC/four-meme-api/.
Офлайн-тесты: python3 -m unittest discover -s tests -p 'test_bnb_monitor.py'.
До первого успешного запроса с пользовательским API-токеном интеграция с живым
сервисом остаётся непроверенной. Не объявляйте мониторинг запущенным по тестам.
